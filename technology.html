Technology Stack

Technologies and cloud services proposed for developing the CyberShield AI framework.

Python

Used for data processing, security event analysis and Machine Learning model development.

Machine Learning

Supports threat classification and the identification of suspicious patterns in cybersecurity datasets.

HTML, CSS & JavaScript

Used to develop the website interface, interactive elements and security dashboard.

PHP

Proposed as a backend technology for handling application requests and communication between the interface and database.

MySQL / AWS RDS

Designed for storing application information, security events and related records in a structured database.

AWS S3

Provides cloud object storage for suitable project files, datasets and security-related data.

AWS IAM

Manages identities, permissions and controlled access to AWS resources following the principle of least privilege.

AWS SNS

Supports the proposed notification system for delivering security alerts when configured threat conditions are met.

AWS EC2

Provides virtual computing infrastructure for hosting and running backend application components when deployed.
