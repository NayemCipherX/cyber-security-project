Research & Analysis

An academic examination of existing cybersecurity research, current limitations and the research contribution proposed by CyberShield AI.

1. Research Focus

This research focuses on investigating how intelligent detection techniques can be combined with cloud-based security services. The study examines the relationship between threat classification, cloud event management, security notifications and controlled response mechanisms.

4. Identified Research Challenges

Based on the selected literature, several challenges deserve further investigation:


Detection Reliability

A detection model must distinguish suspicious activities from legitimate behavior while controlling false positive and false negative results.


Data Quality and Diversity

Machine learning performance can be affected by incomplete, imbalanced, outdated or insufficiently representative datasets.


Cloud Security Integration

Integrating detection results with cloud storage, access management and notification services requires secure communication and reliable event handling.


Operational Response

Detection alone is not enough. Security notifications and response actions should be timely, authorized and properly recorded.

5. Research Gap

The selected studies provide substantial discussions of AI-driven intrusion detection and machine learning applications in cloud security. However, this project investigates an integrated implementation approach that connects threat classification with cloud-based event management, notification and controlled response.

The research will examine how these components can work together in a single proposed cybersecurity framework. This is the project's investigation area, not a claim that no previous system has attempted similar integration.

6. Proposed Research Contribution

CyberShield AI proposes to investigate an integrated framework with the following research contributions:


1. Intelligent Classification: Investigate a Python-based machine learning model for identifying potentially malicious security events.


2. Cloud-Based Event Management: Explore AWS services for storing and managing security-related records.


3. Security Notifications: Design an AWS SNS-based notification mechanism for configured threat conditions.


4. Controlled Response: Investigate authorized response mechanisms and maintain records of security actions.


5. Performance Evaluation: Evaluate the proposed detection model using suitable classification metrics and controlled test scenarios.

7. Research Questions

RQ1: How can machine learning techniques support the classification of suspicious security events?


RQ2: How can AWS services support secure management of security-related information?


RQ3: How can notification mechanisms improve awareness of detected security events?


RQ4: How effectively can the proposed framework perform under controlled evaluation scenarios?

8. Research Scope and Limitations

This project focuses on a prototype framework using selected datasets, machine learning techniques and AWS services. Its findings will depend on the chosen dataset, model, configuration and testing environment.

The prototype will not claim to detect every cyber attack or replace a complete enterprise security platform. Its capabilities and limitations will be documented through experimental evaluation.
